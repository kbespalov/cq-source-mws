# Security

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/kbespalov/cq-source-mws/security/advisories/new).
Do not open a public issue for a leak or an exploitable flaw.

This plugin lists metadata. It must never persist secret material (API keys,
HMAC secrets, private keys, Secret Manager payloads). See
[CONTRIBUTING.md](CONTRIBUTING.md).
